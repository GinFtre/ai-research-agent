我构建了一个面向酶催化连续流反应的科研 Agent 系统，用于自动完成文献解析、实验条件提取与正交实验设计优化。

该系统能够自动读取 PDF 文献，提取反应温度、底物比、流速、酶载量等关键参数，并基于历史实验结果自动生成下一轮正交实验方案。Agent 内部采用多阶段链式推理，包括：

文献解析 Agent
动力学参数提取 Agent
DOE（实验设计）优化 Agent
数据分析与结果评估 Agent

系统能够自动筛除不合理参数组合，并依据已有实验结果动态调整变量范围，实现实验条件迭代优化。

目前该系统已用于脂肪酶催化甘三酯连续流酯交换实验，累计辅助生成 50+ 组实验条件，减少约 70% 的人工文献整理时间，并显著降低重复实验比例。
